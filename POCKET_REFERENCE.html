Runbook: Host Completely UnpingableNetwork
  1. Check physical link / Wi-Fi association: ip link show
  2. Check Default Gateway: ip route show
  3. Test loopback ping: ping -c 2 127.0.0.1
  4. Check DNS resolver: resolvectl status
  5. Flush and restart adapter: systemctl restart NetworkManager
Runbook: Root Filesystem at 100% FullStorage
  1. Find top 10 largest folders: du -ahx / | sort -rh | head -n 10
  2. Clear apt cache: apt-get clean && apt-get autoremove -y
  3. Vacuum systemd logs: journalctl --vacuum-time=2d
  4. Check unlinked deleted open files: lsof +L1
  5. Clear temporary files: rm -rf /tmp/* /var/tmp/*
